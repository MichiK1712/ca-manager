Anleitungen

Schritt-für-Schritt für jeden Zertifikatstyp.

Root-CA vertrauen (alle Certs gültig)
  1. Im Bereich Root-CAs → Download klicken (bekommst die .crt).
  2. Auf dem Rechner dem OS bzw. Browser vertrauen:
# Debian/Ubuntu
sudo cp root.crt /usr/local/share/ca-certificates/root.crt
sudo update-ca-certificates

# RHEL/Fedora/CentOS
sudo cp root.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
Server-Zertifikat in nginx verwenden
  1. Zertifikat ausstellen (Typ Server, CN = Domain, SANs = alle Domains/IPs).
  2. Rechts .crt (Zertifikat), .key (Key) und fullchain (cert + CA) laden, nach /etc/nginx/ssl/ kopieren.
server {
  listen 443 ssl;
  ssl_certificate     /etc/nginx/ssl/nas.local.crt;
  ssl_certificate_key /etc/nginx/ssl/nas.local.key;
}

Für fullchain.pem (falls Client die CA nicht kennt): ssl_certificate /etc/nginx/ssl/nas.local.fullchain.pem;

mTLS / Client-Zertifikat in nginx
  1. Zertifikat ausstellen (Typ Client, CN = Benutzername).
  2. Root-CA .crt als Vertrauensanker auf den Server legen.
  3. Client bekommt .crt + .key (oder p12 für Browser).
server {
  ssl_client_certificate /etc/nginx/ssl/root-ca.crt;
  ssl_verify_client on;
}
SSH-CA — Server einrichten (User-Login)
  1. Im Bereich SSH-CA eine SSH-CA anlegen (z.B. Home SSH CA).
  2. Public Key laden → als /etc/ssh/ssh-ca.pub auf den Server legen.
  3. In /etc/ssh/sshd_config eintragen und sshd neu laden.
# /etc/ssh/sshd_config
TrustedUserCAKeys /etc/ssh/ssh-ca.pub
sudo systemctl reload sshd
SSH-CA — Client-Zertifikat nutzen
  1. Client erzeugt sich ein Schlüsselpaar (falls noch nicht vorhanden).
  2. Public Key-Inhalt an dich (Admin).
  3. Du signierst ihn im Bereich SSH-CA → Zertifikat signieren (Typ User, Principals = Usernames).
  4. Client lädt die *-cert.pub und legt sie neben seinen privaten Key.
# auf dem Client
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519   # einmalig
# signiertes cert.pub neben den Key legen:
#   ~/.ssh/id_ed25519-cert.pub

Beim Login wird die Identität jetzt über den CA verifiziert — ablauf- und widerrufbar, kein Passwort nötig.

SSH-CA — Host-Zertifikat (Host-Auth)
  1. Public Key des Hosts (/etc/ssh/ssh_host_*_key.pub) holen.
  2. Im Bereich SSH-CA → Zertifikat signieren: Typ Host, Principals = Hostnamen + IPs.
  3. Download als /etc/ssh/ssh_host_ed25519_key-cert.pub ablegen.
  4. In /etc/ssh/sshd_config referenzieren.
HostCertificate /etc/ssh/ssh_host_ed25519_key-cert.pub
